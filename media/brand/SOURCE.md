# 项目标识

`doubo.png` 是用户提供的原图，未裁切或改色。
来源文件：`微信图片_20261028141600_235_847.png`（1794 × 876，1,563,032 字节）。

API 启动后，将它同步到当前环境 OSS 的 `system/brand/<SHA256>/doubo.png`。
对象保持私有；接口提供 24 小时有效的 HTTPS 签名地址，并在签名中包含等比缩放到
400 像素宽的 OSS 图片处理参数。原始文件仍保留在 OSS，页面不下载原图。

小程序授权页、登录页和管理后台登录页、侧栏使用同一张图片。后台 favicon 通过
`/api/brand-icon` 获取新签名；未完成同步时使用部署目录中的原图兜底。
`/api/branding` 无需登录，也不依赖数据库；小程序 `/api/config` 同时返回 `brandIcon`。

从 `server` 目录手工同步时，先设置对应环境的 `OSS_*`，再运行：

```sh
go run ./cmd/sync-model-icons -brand -dir ../media/brand -bucket douboai-test
```

原图仅随后端媒体目录部署，不打入小程序或 Web JS/CSS。
