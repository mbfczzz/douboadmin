# 小程序内置图片（不上传阿里云）

> **阿里云 OSS：不需要上传。** 本目录随小程序代码包一起，通过微信开发者工具上传到微信。
> 需要上传阿里云 OSS 的是 `media/ui-art/`（24 张在线配图，部署时自动同步），见 `media/ui-art/README.md`。

这些图片要和页面同时出现（包括断网时的空状态），所以打包在本地，不走网络。均由 Codex 生成。

| 目录 | 内容 | 格式 |
|---|---|---|
| `photos/` | 默认头像、积分、服务商中心、还没有作品、积分套餐/订单分档商品图（`tier-1` 至 `tier-4`），以及各页空状态（未登录、无消息、无订单、断网、无搜索结果、等待开通、模板下架、视频不可用） | JPG 缩略图 |
| `glyphs/` | 内容类图标（作品操作、设置、混剪、上传、Agent、弹窗、积分明细等），同一套粗线条 | 带透明通道的 PNG，颜色写在文件名里：无后缀白色、`-muted` 灰、`-danger` 红、`-brand` 青、`-dark` 深色（用于浅色底）、`-lg` 大尺寸 |
| `tab/` | 底部导航 5 个图标 | PNG，`-on` 选中白色、`-off` 未选中灰色 |

约定：

- 新增或替换图片后运行 `node --test scripts/assets.test.cjs`：页面引用的每张图都必须存在，目录里不能有未被引用的文件（避免上传包带无用图片）。
- 箭头、关闭、勾选、加载、状态等系统控件仍使用 TDesign 图标。
- 本说明文件已在 `project.config.json` 中排除，不进入上传包。
