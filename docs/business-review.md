| 问题 | 修复与验证 |
| --- | --- |

| 同一幂等请求返回原任务时，漏掉当前积分预留和阶段信息 | 重复提交返回前同样补齐当前业务状态，并有接口回归。 |

| 准备分享期间改变“包含创作描述”，旧响应可能展示带原隐私配置的链接 | 修改标题/隐私选项、离开页面、审核失效都会使旧请求失效。已失效的公开分享重新进入后清空旧作品。 |
| 离开通知/订单页面或退出登录后，迟到响应可能跳转、更新 UI 或恢复分析授权 | 添加生命周期与会话检查，重复点通知仅处理一次；会话过期清空积分、订单、通知、偏好等旧数据。 |
| 清空搜索历史后，旧查询响应可将历史重新显示 | 清空操作同步使此前查询失效。 |
