# 创作页任务数量提示

“任务队列”入口旁显示小字“当前 N 个任务在生成”。仅统计当前账号 `running` 状态的任务，排除 Agent 对话与素材导入；排队、完成、失败不计入。数量为 0 时不显示提示。

使用 `/api/jobs?page=1&size=1&status=running&excludeChat=true&excludeImport=true` 返回的 `total`，不以当前页条数统计，因此不受任务列表分页限制。后端增加对既有 `ExcludeImport` 过滤条件的查询参数支持，无数据库迁移。

页面可见时立即刷新，之后每次请求完成后间隔 5 秒刷新，避免请求重叠。离开页面、退出账号或遇到 401/403 时停止；晚到的旧请求不覆盖新页面/新账号。未登录不请求，不弹登录框；网络异常隐藏提示，随后重试。

需部署 API 并更新小程序。源码依赖估算从 753,494 增至 755,987 字节（+2,493，约 2.43 KiB），第三方引用仍为 200,161 字节，无新增依赖或图片。原 736 KiB 预算仅余 170 字节，针对这项实时数量功能调整到 740 KiB；保留编译、文件长度和预算检查。该估算不是微信最终上传包。
