# 应用登录密码规则

新建、修改、重置及自动生成的应用登录密码统一为 **正好 8 个 ASCII 字符**：仅允许 `A-Z`、`a-z` 和 `0-9`，必须至少有一个大写字母及一个小写字母。数字可选；禁止空格、中文、全角字符、标点和特殊符号。

服务端由 `passwordpolicy` 统一校验；后台账号、服务商账号、自助修改密码及首次创建超级管理员都调用同一规则。后台随机生成保证两个大小写类别并打乱字符位置。按最新权限要求，小程序服务商中心的一键开通和重置入口已取消，由超管统一管理账号；本人在后台修改密码仍保留。

已有密码哈希不批量重置：旧账号可继续登录，并在下一次修改/重置时应用新规则。登录页和“当前密码”不限制为8位，以免锁住旧账号。现有数据库账号存在时，旧的引导环境密码不阻止服务启动；空库首次创建超级管理员需要合规的 `ADMIN_PASSWORD`，生产环境禁止使用开发默认密码。数据库迁移命令不会在建表前读取账号表。

本规则用于豆播登录账号，不修改 MySQL、Redis、微信 AppSecret、OSS 密钥等第三方连接凭据，也不更改现有线上账号密码或会话。
