# 应用登录密码规则

新建、修改、重置及自动生成的应用登录密码统一为 **正好 8 个 ASCII 字符**：仅允许 `A-Z`、`a-z` 和 `0-9`，必须至少有一个大写字母及一个小写字母。数字可选；禁止空格、中文、全角字符、标点和特殊符号。

服务端由 `passwordpolicy` 统一校验；后台账号、服务商账号、自助修改密码及首次创建超级管理员都调用同一规则。后台随机生成保证两个大小写类别并打乱字符位置。按最新权限要求，小程序服务商中心的一键开通和重置入口已取消，由超管统一管理账号；本人在后台修改密码仍保留。

已有密码哈希不批量重置：其他旧账号可继续登录，并在下一次修改/重置时应用新规则。登录页和“当前密码”不限制为8位，以免锁住旧账号。配置文件指定的初始 ADMIN 在每次 API 启动时按 `ADMIN_USER`、`ADMIN_PASSWORD` 创建或同步；配置密码须符合8位规则，生产环境禁止开发默认密码。密码未变时不重写哈希或使会话失效，密码变化时旧会话失效。Worker 和数据库迁移命令不执行管理员同步，迁移不会在建表前读取账号表。

本规则用于豆播登录账号，不修改 MySQL、Redis、微信 AppSecret、OSS 密钥等第三方连接凭据。初始 ADMIN 同步只在部署新版 API 并启动时发生。
