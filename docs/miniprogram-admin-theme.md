# 管理后台与小程序参考主题

- 产品：豆播 AI，让用户选择模型、提交创作并管理作品与积分。
- 气质：专注、鲜明、有创作感，采用用户指定参考站的深色工作台主题。
- 场景：石墨黑的创作工作台，深灰容器承载编辑、交易与管理信息。
- 色彩重点：真实作品封面、珍珠白主操作和冰蓝选中态，绿色辅助操作、玫红登录与充值。
- 识别细节：保留用户提供的蓝色品牌图，两端沿用参考站的亮色导航选择与深色编辑区。

## 视觉依据与范围

用户在 2026-11-11 将视觉依据明确改为 [aggc.site](https://aggc.site/)，管理后台和小程序一起调整。已通过用户授权账号观察默认深色主题的登录、创作、模型、历史与移动端创作页；仅参考主题与组件语言，不复制站点品牌、业务文案和数据。资产页返回 403，不作为设计依据。

背景 `#101113`、容器 `#1a1b1f`、输入面 `#202125`、浮层 `#2d2f34`；正文 `#f5f6f7`、次要文字 `#c5c8ce`、辅助文字 `#969ba4`。普通主操作采用珍珠白底与深色字，绿色 `#22c55e` 用于辅助操作和焦点。选中导航使用珍珠白到冰蓝的浅色渐变并配深色字；登录、充值采用玫红。成功 `#32d47a`、警告 `#f5c84b`、错误 `#f05252`、处理中 `#22d3ee` 独立表达状态。

按钮与输入沿用 8px 控件尺度，普通容器 10px，创作工作台 14px，原生弹层保留 TDesign 圆角；标题字重以 600 为主，保留移动端触控尺寸与安全区域。当前模型图标、二维码和作品图片保留原始颜色。功能顺序、页面路径、业务文案与权限逻辑沿用现有实现。

参考站的玫红 `#f20d7a` 在小字号白字按钮上不足 4.5:1，因此实际登录/充值底色略调深为 `#e10b72`，保持同一色相并通过对比度测试。珍珠白主操作、暗色选中项、绿色成功提示及红色错误提示分别验收，避免只换主色后丢失状态差异。

## 验证边界

检查公共主题、TDesign 变量、所有页面及组件中的旧色、原生 switch/slider、窗口背景和返回后的背景一致性。通过独立浏览器样式预览核对布局和对比度；用户正在使用模拟器，本轮不操作该模拟器，真机与最终微信上传包单独验收。

本次参考 Impeccable 与 Unslop 的检查方法；Unslop 作者为 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)），CC BY 4.0。

## 状态复查

SDK 实际按钮样式复现了四个遗漏：登录按下后白字落在冰蓝底；默认按钮按下回到浅灰底；文字按钮按下回到近白底；次要禁用按钮继承半透明黑字。统一补齐暗色激活面、禁用文字/边界，以及登录页自己的深玫红按下色。后台登录补充悬停反馈，禁用按钮排除悬停换色；日期选择器可选的跨月日期从低对比灰提升至公共辅助色。底栏选中图标不再从 24px 缩为 18px，切换时保持图标尺度稳定。

五项原始回归在修复前均失败；修复后扩大到 8 项状态回归（含 SDK 描边按钮），结合参考页面与底栏布局共 23 项通过。新增对比度断言、小程序与 Web 构建及体积检查通过，日志为 `.runtime/theme-states-before.log`、`theme-states-final.json`、`theme-recheck-mini-build.log`、`theme-recheck-web-build.log`。SDK 状态测试使用已安装版本的 CSS，与手绘控件预览区分；依然不等同于微信真机渲染验证。
