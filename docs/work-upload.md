# 为用户上传作品

管理后台「作品管理 → 上传作品」（仅超级管理员）可以把一段 MP4 视频（500 MB 以内）放进指定用户的「我的作品」。用户用手机号或用户编号指定，已停用或已删除的用户不能上传。

## 与已发布小程序的兼容

接口 `POST /api/admin/works`（multipart：`user`、`title`、`file`）不新增小程序依赖，现有小程序无需发版：

- 作品按普通视频作品保存：任务类型 `video`、状态成功、结果是该用户名下的素材，进度 100。小程序的作品列表、播放、保存、分享、删除、优秀作品都按原有流程工作；视频封面沿用 OSS 首帧截图。
- 作品标题写入提示词字段，列表和详情直接显示；模型名显示为「用户上传」。
- 输入中新增 `source: "upload"` 标记，旧版小程序忽略该字段。
- 旧版小程序在作品详情仍显示「再编辑」，点击后以标题作为描述打开创作页，不会报错；新版可按 `source` 隐藏。

## 不计入生成

上传作品不进入生成队列、不扣积分（账务记录为 `free`，消耗积分显示 0），也不计入工作概览的生成次数、成功率、积分消耗及用户的模型使用统计。

## 注意

用户上传的内容没有生成模型的上游安全审核，设为优秀作品或公开分享前请人工确认内容合规。

## 大文件上传

上限 500 MB。该接口单独放宽了 API 的读写时限（20 分钟，其余接口仍为 90 秒），视频先暂存到 API 的临时目录再传到 OSS，不读入内存。Nginx 需为该接口单独放宽请求体大小和超时，见 `deploy/native/nginx.conf.example` 中的 `location ~ ^/api/(assets(/[^/]+/reference-clip)?|admin/works)$`（小程序素材上传 `/api/assets` 的视频同样最大 500 MB，图片、音频仍为 50 MB）；上传期间临时目录约需与视频同等大小的磁盘空间。
