# 小程序授权开通页：扫码取景框与邀请码输入（体积说明）

授权开通页的"扫码登记"从文字按钮改为可点击的扫码取景框（四角青色框、扫码图标、缓慢移动的扫描线，减少动效时静止）；邀请码改为 8 格分段输入：

- 4 + 4 两组之间固定显示"-"，"-"只用于显示，提交和复制都是 8 位原码；
- 输入时自动转大写，去掉码中不会出现的字符（I、O、0、1、符号）并提示；
- 当前格高亮并显示光标，输满 8 位后整组变为青色、"确认登记"变为主按钮；
- 一键"粘贴"，可粘贴邀请码或二维码内容（`DOUBO-SHARE:` 前缀会自动去掉）；
- 服务商中心的码继续显示为 `KMNP-2345`，与管理后台一致。

实现：取景框和分格样式在 `pages/activate/entry.wxss`；一个隐藏的原生 input 负责键盘、退格和粘贴，`pages/activate/code-entry.ts` 负责格式化，
`services/access.ts` 提供 `typedCode` / `prettyCode`，服务商页复用同一个显示函数。无新依赖，
不新增 TDesign 组件。
