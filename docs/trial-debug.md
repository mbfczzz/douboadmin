# 体验版默认调试

2026-11-13 用户确认：体验版默认开启调试，当前测试接口仍使用 HTTP 公网 IP。

- 仅 `envVersion === "trial"` 自动开启 `wx.setEnableDebug`，每次冷启动执行一次，覆盖以前保存的关闭状态。
- 启动配置、微信登录交换、使用权限查询及上传共用开启 Promise；成功回调前不发网络请求。失败或五秒超时会提示开启失败，重试可以重新开启，不会一直卡住。
- 设置页连续点击“当前版本”五次仍可手动关闭，本次运行保持关闭；下次冷启动体验版再次默认开启。
- 正式版、开发版和无法识别版本的环境不自动开启。正式版启动清理从体验版遗留的自动调试标记，保留用户主动开启的选择。

需要重新上传小程序体验版，并在手机完全退出后重新进入。服务器重新部署不会更新已上传的小程序代码。调试开启会出现 vConsole；是否能够访问当前 HTTP 接口仍需微信真机验证，不能将此开关视为正式版 HTTPS 合法域名配置的替代。

验证：调试状态、开启失败、超时、重试、正式版隔离和真实请求包装层的先后顺序回归；23 页微信编译通过。引用源码依赖估算为 722056 字节，比前一版增加 1213 字节，无新依赖、未提高预算。该值不是微信最终上传包，最终上传包未测量。
