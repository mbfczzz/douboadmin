# 体验版测试环境与调试

体验版连接测试接口 `http://106.15.92.153:8088`，正式版继续连接生产 HTTPS。

- 仅体验版冷启动自动开启 `wx.setEnableDebug`。
- 配置、登录、授权查询和上传会等待调试开启完成再发请求，避免 HTTP 测试接口在调试生效前被拦截。
- 正式版和开发版不会自动开启；正式版会清理体验版遗留的自动调试状态。
- 设置页连续点击“当前版本”五次仍可手动切换调试控制台。

本配置只用于体验测试，不能代替正式版的 HTTPS 合法域名。切换版本后需要在手机完全退出旧小程序再重新进入。

验证覆盖环境隔离、调试失败重试、并发首批请求等待以及正式版清理逻辑；微信最终上传包由开发者工具单独检查。
