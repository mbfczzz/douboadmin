## 实施边界

- 当前本机数据库与明确标注的预览模板继续用于开发。测试数据库和 OSS 由用户后续提供。
- 支付、抖音数据、语音识别等没有真实凭证时保持未启用，不能用模拟成功替代。
- 支付到账只接受可信服务端通知或主动查单，不信任小程序支付回调。
- 上游提交状态不确定时不重复生成；积分保留待核实，防止重复收费与重复发放。
- 备案和提审须有实际平台回执后才能标记完成。
