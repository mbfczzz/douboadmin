## 增长用途与控制

- “我的”页增加真实统计、最近两件作品及失败重试、按角色显示的功能宫格；图片来自接口，无新本地图片。只请求第一页两件已完成作品，失败保留用户资料。
- 积分页增加图标、预留说明、适配单/双/多套餐、选中金额确认；订单页增加商品名、状态、金额与积分对照、复制订单号和图文操作。
- 创作按钮回到输入卡片中；按后续真机反馈，模型、积分/参数摘要与生成操作改为同一行，长模型名省略，金额不截断。可用余额复用积分组件，与字数统计同排放在输入卡片内，移除参数区下方的重复余额；加载失败可原位重试。删除示例入口、默认示例文案、推荐词状态和对应样式。
- 延用原生 TypeScript + TDesign，无新依赖，第三方引用量不变。拆分“我的”内容样式，手写文件均小于 300 行。公共积分组件和列表样式复用，不将 SVG 设计稿、预览工具及测试装入小程序。

后台只为本人已完成的任务附带已有缩略图能力，不改变任务读取权限、原始结果和支付逻辑；旧服务器没有缩略图字段时图片回退原结果，视频显示媒体图标。

管理后台产品源码和 Web 首屏静态依赖没有改动，本轮 Web 仅更新布局投影测试。微信最终上传包仍须由微信开发者工具单独核验；测试和源码估算不能替代真机视觉验收。
