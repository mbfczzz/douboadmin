# 参考图片预览与引用

创作页点击已上传参考图可在参考素材查看器中放大；删除按钮阻止事件冒泡。

在提示词输入 `@` 时，在光标相邻位置显示紧凑的参考图列表，插入 `@图片1` 等文本引用。序号按当前参考图片的顺序，不包含视频/音频，图片较多时可在浮层内滚动。去掉底部弹窗和页面遮罩，避免与键盘和输入框冲突。上传素材及原有模型输入数组保持原逻辑，引用文本与描述一起发送；具体理解仍取决于所选模型。

浮层用原生 cover-view / cover-image 显示，选择时保持键盘，插入后恢复输入焦点与光标。隐藏的同字体文本用来估算 @ 位置；接近屏幕边缘或键盘时切换到下方/上方并限制在可视区域，长文本内部滚动时贴近当前可见输入区。页面滚动及键盘高度变化时重新测量，继续输入、点击其他位置或收起键盘时关闭浮层。24 项相关测试、24 页原生编译和 320/390/430px 浏览器布局投影通过；尚未进行 iOS 真机键盘联调。

本轮引用源码依赖估算为 769451 字节（不是微信最终上传包），在已有 752 KiB 预算内，没有新增依赖或提高预算。

选图期间提示词或素材列表改变时丢弃旧选择；不自动发起生成或扣积分。取消保留原输入，没有图片时提示先添加。删除图片会移除该图的引用，并将后面的图片编号前移。插入不能超过模型提示词字数限制。

## 引用视频与“已引用”缩略图

- `@` 弹窗同时列出参考图片和参考视频：先图片后视频，各自按素材条顺序编号（`@图片N`、`@视频N`，与任务详情一致）；视频显示首帧封面，没有封面时显示视频图标。删除某个素材时，只给同类后面的引用顺延编号。
- 输入框下方原先的“输入 @ 可引用…”提示，在描述里出现有效引用后改为“已引用”缩略图条：按首次出现顺序、每个素材一次，图片显示图片小图，视频显示首帧小图加播放标记。由页面内 WXS（`pages/create/mentioned.wxs`）根据描述实时计算，不额外 setData。
- 点击缩略图放大：图片进入页面内预览（可引用 / 删除），视频用 `wx.previewMedia` 全屏播放（带封面）。参考素材条里的视频同样显示封面并可点击播放。
- 服务端：`POST /api/assets` 与 `GET /api/assets/{id}` 对视频素材额外返回 `thumbnailUrl`（OSS 截取首帧，带短期签名）；截帧失败时照常返回视频本身。

## 引用显示为内联标签

- 创作框：键盘收起（未在输入）且描述中有有效引用时，输入框显示为“文字 + 引用标签”的只读视图，标签为小图 + `图片N` / `视频N`；点击文字回到输入（光标在末尾），点击标签放大图片或播放视频。输入时仍是普通文字（微信 textarea 不能在文字中嵌入图片）。
- 任务详情的提示词卡片同样以标签显示引用，点击图片标签打开图片预览，视频标签全屏播放。
- 解析在共用 WXS `utils/mentions.wxs`（`segments` / `list` / `any`），无效引用（如没有对应素材的 `@图片9`）保持原文字。
