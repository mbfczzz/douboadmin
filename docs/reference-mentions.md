# 参考图片预览与引用

创作页点击已上传参考图可在参考素材查看器中放大；删除按钮阻止事件冒泡。

在提示词输入 `@` 时，在光标相邻位置显示紧凑的参考图列表，插入 `@图片1` 等文本引用。序号按当前参考图片的顺序，不包含视频/音频，图片较多时可在浮层内滚动。去掉底部弹窗和页面遮罩，避免与键盘和输入框冲突。上传素材及原有模型输入数组保持原逻辑，引用文本与描述一起发送；具体理解仍取决于所选模型。

浮层用原生 cover-view / cover-image 显示，选择时保持键盘，插入后恢复输入焦点与光标。隐藏的同字体文本用来估算 @ 位置；接近屏幕边缘或键盘时切换到下方/上方并限制在可视区域，长文本内部滚动时贴近当前可见输入区。页面滚动及键盘高度变化时重新测量，继续输入、点击其他位置或收起键盘时关闭浮层。24 项相关测试、24 页原生编译和 320/390/430px 浏览器布局投影通过；尚未进行 iOS 真机键盘联调。

本轮引用源码依赖估算为 769451 字节（不是微信最终上传包），在已有 752 KiB 预算内，没有新增依赖或提高预算。

选图期间提示词或素材列表改变时丢弃旧选择；不自动发起生成或扣积分。取消保留原输入，没有图片时提示先添加。删除图片会移除该图的引用，并将后面的图片编号前移。插入不能超过模型提示词字数限制。
