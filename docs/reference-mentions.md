# 参考图片预览与引用

创作页点击已上传参考图可通过微信原生图片预览放大；删除按钮阻止事件冒泡。

在提示词输入 `@` 时，通过微信原生选择列表选择当前上传的参考图，插入 `@图片1` 等文本引用。序号按当前参考图片的顺序，不包含视频/音频。五张以上通过“更多图片”切换，每次最多五张加一项导航，不增加 TDesign 组件或依赖。上传素材及原有模型输入数组保持原逻辑，引用文本与描述一起发送；具体理解仍取决于所选模型。

选图期间提示词或素材列表改变时丢弃旧选择；不自动发起生成或扣积分。取消保留原输入，没有图片时提示先添加。删除图片会移除该图的引用，并将后面的图片编号前移。插入不能超过模型提示词字数限制。
