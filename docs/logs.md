# 日志管理

后台「平台管理 → 日志管理」记录用户和管理员的每一次操作，按用途分五个标签。菜单权限为 `logs`（超级管理员和平台运营默认可见，服务商角色不可授予）。

| 标签 | 记录内容 | 来源 |
| --- | --- | --- |
| 业务日志 | 有业务含义的写操作：谁、何时、对什么对象、做了什么、结果。例如“超级管理员（admin）给用户 张三 调整积分：增加 50 积分（活动补偿）” | 每个写接口按路由映射为中文操作名（`server/internal/api/audit_ops.go`），并从路径和参数提取对象与摘要 |
| 接口日志 | 每一次 `/api` 调用：调用方、方法、路径、路由、状态码、耗时、IP、客户端、请求参数和返回内容 | HTTP 中间件 |
| 模型调用 | 每一次向上游中转的调用：提交生成、查询结果、同步模型目录；所属用户与任务、模型、参数、上游返回、错误 | 中转客户端 `relay.Client.Observe` |
| 积分变动 | 每一笔积分流水：用户、类型、可用/预留变动、变动后余额、操作人（管理员或系统）、原因与关联单号 | 直接读取积分流水 `wallet_ledger`，与用户钱包是同一份数据 |
| 登录日志 | 管理员登录、用户微信登录、退出登录，包括失败的登录 | 同接口日志，分类为 `auth` |

每条日志可点「详情」查看完整记录，包括格式化后的请求参数和返回结果。

## 记录规则

- **调用方**：认证通过后即记录，被拒绝（401/403）的请求也能看到是谁。管理员显示“姓名（账号）”，用户显示昵称；名称在写入时解析并保存，读取时不再查询。
- **请求参数**：写操作记录请求体，读请求（GET）只记录路径和查询参数。上传文件只记录类型和大小。
- **返回内容**：写操作和失败请求（状态码 ≥ 400）记录返回体；成功的读请求只记录字节数，避免列表轮询撑大日志。
- **脱敏**：字段名为密码、密钥、令牌、签名、AppSecret、API Key、AES Key 等（包括 `WECHAT_APP_SECRET`、`RELAY_API_KEY` 这类配置名）以及请求中的 `code`（微信登录码、激活码）一律显示为 `***`。另外，已配置的密钥值无论出现在哪个字段都会被替换。
- **截断**：单个请求或返回最多保存 16 KB；内联图片（base64）、超过 2000 字的文本只保留开头并注明总长度；超过 1 MB 的上游返回只记录大小。
- 不记录：健康检查、匿名访问统计上报（`/api/visits`、`/api/events`）、查看日志本身的请求。

## 性能

- 请求结束后把日志放入内存队列（8192 条）立即返回，不等待写库；后台单个协程每 500 毫秒或每 200 条批量写入一次（MySQL 多行插入）。
- 队列满时丢弃新日志并计数（`GET /api/admin/audit/stats` 的 `dropped`），绝不阻塞业务请求。
- MySQL 使用独立的 `audit_logs` 表（`server/internal/store/audit_mysql.go`），不占用业务表；按分类、操作人、对象、时间建索引。列表按时间有序的编号做游标分页，不做 `COUNT` 和 `OFFSET`，日志再多翻页也只读一页数据；列表不读取请求/返回正文，打开详情时才读取。
- `audit_logs` 表由数据库迁移创建；部署脚本会先运行 `doubo-migrate` 再启动服务，手动部署时执行 `doubo-server migrate`。

## 保留期限

每天自动清理一次：

| 环境变量 | 默认 | 含义 |
| --- | --- | --- |
| `LOG_RETENTION_DAYS` | 180 | 写操作、登录和模型调用日志保留天数 |
| `LOG_READ_RETENTION_DAYS` | 14 | 读请求（GET）日志保留天数 |

内存存储（开发环境）只保留最近 50,000 条。积分变动来自积分流水本身，不受日志清理影响。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/audit?tab=business\|api\|model\|auth` | 日志列表；可选 `actor`、`target`、`q`、`status=ok\|fail`、`method`、`writes=1`、`from`/`to`（`YYYY-MM-DD`，北京时间）、`before`（游标）、`limit`（≤100） |
| GET | `/api/admin/audit/{id}` | 单条日志，含请求与返回 |
| GET | `/api/admin/audit/points?user=&q=&page=` | 积分流水（含用户昵称和操作人） |
| GET | `/api/admin/audit/stats?days=7\|30\|90` | 接口请求量、错误、慢请求、平均耗时（缓存 1 分钟） |

工作概览的「服务接口」指标随 `GET /api/admin/dashboard` 的 `api` 字段一起返回，不额外请求；同样缓存 1 分钟。
