| 优先级 | 问题 | 修复与回归 |

| P1 | 读取删除标记或账号状态异常时，公开分享仍可能返回作品 URL | 公开访问使用独立的严格检查，不能确认状态时拒绝；验证账号存在、未停用、作品未删除、审核通过。存储故障注入曾复现 200，修复后返回不可访问。 |

| P2 | 部分仅支持全能参考/首尾帧的模型，在省略 mode 时被错误推断；推断值没有写入任务快照 | 按模型可用能力推断并保存 mode，使参数校验与供应商请求一致；契约测试验证上游请求中的 mode。 |
| P2 | 只校验参考图最大数量，没有校验上游最小数量 | 下发并校验 minCount，小程序提交前拦截，API 再次校验。 |
| P2 | 系统选图期间后台配置已失效，仍先上传再发现不支持 | 上传前使用已更新配置重新校验，保留上传后的再次校验。 |

| P2 | 离开热门视频详情后，迟到的导入失败响应继续更新页面 | 页面销毁后丢弃回写，不再弹出旧页面错误或触发跳转。 |

## 2026-11-02：三轮逻辑与代码复查

### 第一轮：后端权限与事务一致性

检查激活、名额、充值、分佣、退款、账号停用与钱包锁顺序。先跑已有基线，再补失败用例复现：入口鉴权之后若账号被停用，激活事务仍可能消费授权码，新充值订单也可能创建；激活还未严格拒绝 `null` 或错误类型的账号资料。

### 第二轮：客户端时序、重复操作与草稿

- 小程序旧账号请求迟到的 401 会先执行过期处理，可能把新账号送回授权页。普通请求先比较发送时的存储会话快照，上传响应先核对会话，再处理 401；真正属于当前会话的过期响应仍正常处理。
- 模型和模板保存期间，仅禁用了提交按钮，字段仍可编辑，成功关闭弹窗会丢掉晚输入的修改。保存中使用禁用字段组锁定输入；失败后恢复编辑并保留草稿。焦点循环排除继承禁用状态的字段。
- 修复回归发现原生 fieldset 的滚动行为与 div 不同，已保留独立滚动容器，不让输入锁定影响固定保存栏。

失败复现在 `.runtime/round2-mini-repro.log`、`.runtime/round2-web-repro.log`；定向复测在 `round2-mini-fixed.log`、`round2-web-fixed.log`。新增测试为 `miniprogram/scripts/session-isolation.test.cjs` 与 `web/tests/editor-pending.spec.ts`。

- 验证停用前已创建订单的有效到账仍正常入账，重复回调只加一次积分。

本轮修复：

- 小程序每次进入/返回重放整页透明度动画、600 ms 中间页、模型重复请求及迟到回调导致闪屏或干扰新页面。保留原生跳转、缓存页内容和草稿，修复 Tab 高亮与失败解锁。

- 私有图片的旧签名失效后，放大预览仍使用旧地址。现在按素材 ID 重新授权读取最新 URL，拦截重复点击，离开页面后取消打开操作。
