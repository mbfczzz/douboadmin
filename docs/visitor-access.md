# 游客登记与开通

待审核账号统一视为游客。游客可以进入小程序各页面并读取模板、模型、个人资料、历史记录、钱包和订单等只读数据；页面和底部导航不做限制。提交生成、Agent对话、上传素材、支付、收藏、修改资料等会产生业务结果的接口由服务端拦截，并提示“账号待管理员开通，暂不可使用该功能”。付费上游查询等具有外部成本的读取接口也继续拦截。

推广码登记只创建独立游客登记，保留推广人和其所属服务商，不提前创建合伙人会员关系。管理员通过后才创建有效会员关系，推荐来源不变。

后台开放普通注册时，普通注册不再立即获得 `direct_access`，只在平台总账号下创建独立游客登记；登记类型为 `direct`，没有会员关系、邀请码、推荐人或下级服务商来源。只有超级管理员可以处理这类平台登记。通过后才成为总账号下的合伙人并可生成个人推广码；其推广码带来的游客继续归属总账号并记录推荐人。

历史已存在的有效 `direct_access` 保持可用，不在本次变更中撤销。账号被拒绝、停用或注销时不会保留游客导航状态。

## 管理员身份转换

仅超级管理员可以在用户管理中把游客调整为一级服务商、二级服务商或合伙人；分公司不参与身份转换。新服务商必须选择符合层级规则的上级，合伙人可选择总账号或任一正常分公司、一级服务商、二级服务商。

合伙人或服务商转为游客时不删除关系：合伙人会员记录改为游客保留；服务商负责人关系改为游客保留，服务商节点、原上级、全部下级和分佣历史不变，同时暂停该服务商的后台登录账号。游客期间不能新建、启用、改角色或重置该服务商的后台账号。恢复原服务商身份时重新启用负责人关系和本次暂停的后台账号。有历史服务商节点的用户只能恢复原服务商层级和原上级，避免移动整棵组织树；没有历史服务商关系的游客可以新建一级或二级服务商。

游客身份不写入小程序本地导航状态，权限以服务端登记和接口准入为准。源码依赖估算由 1,139,124 字节增加至 1,139,269 字节，仍在 1113 KiB 预算内。没有新增第三方依赖、媒体资源或数据库表；微信最终上传包需在上传时另行记录。
