# 模型展示排序

在管理后台「模型管理」点击「拖动排序」，拖动左侧手柄，或使用上下移动按钮调整位置。排序窗口加载所有分页的当前模型，不受主列表搜索词限制；已删除模型不参与排序。

可以选择图片、视频等类型。按类型排序时，只调整该类型模型之间的顺序，其他类型的相对顺序保留。也可选择「全部模型」统一排序。

点击「保存排序」并二次确认后生效；取消或关闭窗口不会写入。小程序创作页再次加载配置时，按后台顺序展示可用模型，保留用户已选模型，不强制切换选择。未上架或不可用模型仍不会出现在小程序中。

`PUT /api/admin/models/order` 接收完整当前模型目录的 `items`，每项包含 `id`、`version`、`createdAt`，数组顺序对应排序值 1、2、3……。沿用模型管理权限，事务内统一保存，只改变排序，不更改定价、能力和上下架状态。重复 ID、缺失模型、已删除模型及过期版本均拒绝；发生冲突时回滚全部修改，重新打开窗口或点击「重新加载」后再排序。

后台分页列表、排序窗口、小程序配置统一按排序值升序，排序相同时按 ID 升序。同步上游保留已有模型的排序值。无需数据库结构迁移；需部署管理后台及 API。
