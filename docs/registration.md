# 小程序注册与开通

微信登录后，小程序用户按三步开通：

1. **填写资料**：姓名和有效手机号始终必填；后台开启短信验证时还需输入验证码。关闭时保留手机号输入框，隐藏验证码区域。资料缺失时 `/api/access` 返回 `profileRequired=true`，并通过 `smsRequired` 告知小程序是否需要短信验证。
2. **扫码登记**：在授权页「扫码登记」扫描服务商或会员给的二维码（或输入 8 位码），按码的类型登记为会员、S1 服务商、S2 推荐官，或绑定为后台创建的服务商本人。登记后状态为「待开通」（`access.status=review`）。
3. **总部开通**：待审批时可点击「先浏览小程序」查看模板、模型参数和自己的页面，但不能生成、上传、充值或发码。总部在后台「小程序用户 → 扫码登记」开通后才能使用这些功能；被拒绝（`status=rejected`）可扫其他码重新登记。

不再有「开放普通用户注册」和「跳过直接使用」。已登记或已开通的账号不能再扫码重复登记；解绑或被拒绝后可以重新登记。

**手机号唯一**：一个手机号只能验证一个账号。已被其他账号验证的号码不能获取验证码、不能完成验证，管理员也不能把它填给其他用户。用户换号并验证新号码后旧号码释放；账号归档（注销）后其号码也会释放。

未启用短信时，登记的号码不会创建已验证号码归属；仍会拒绝填写其他账号已验证的号码。启用短信后，未验证号码必须补做验证码验证。

## 短信验证码

使用阿里云短信服务（`dysmsapi`，标准库实现签名，无额外依赖）。在后台「系统设置 → 接入配置 → 短信验证码」填写，保存后重启服务生效：

| 配置 | 说明 |
| --- | --- |
| 开启短信验证 | 关闭时隐藏验证码输入与发送按钮，后端允许无验证码登记；开启时前后端均强制验证 |
| AccessKey ID / Secret | RAM 账号需授予短信发送权限（如 `AliyunDysmsFullAccess`） |
| 短信签名 | 阿里云短信控制台审核通过的签名 |
| 验证码模板 CODE | 验证码类模板，内容须包含 `${code}` 变量 |

开启前须完整填写四项短信凭证；关闭时可保留凭证，以便之后恢复验证。**关闭后填写姓名和手机号即可进入扫码登记**，号码保存为未验证状态，不改变后续审批与授权。保存并重启服务后生效，小程序重新进入授权页读取状态。重新开启后，未验证号码须补做验证；短信服务故障不能自动跳过验证或返回演示验证码。升级前已有完整短信配置且没有开关字段时默认开启，未配置时默认关闭。之后以显式保存的开关为准。无需手动修改数据库。

规则：

- 仅支持中国大陆 11 位手机号；验证码 6 位，5 分钟有效，用后作废。
- 同一用户、同一手机号 60 秒内只能发送一次；同一 IP 每分钟最多 10 次（IP 取自反向代理设置的 `X-Real-IP`）；同一用户、同一手机号每天各最多 10 次。发送失败不计次数，之前收到的验证码仍然有效。阿里云自身的号码频控同样生效。
- 每个验证码最多尝试 5 次（并发提交也逐次计数），超过需重新获取。数据库只保存验证码摘要。
- 短信启用后，手机号须通过短信验证设置，「我的 → 编辑资料」中不可修改，已填写的姓名和手机号不能清空。未启用短信时可以登记未验证号码；更换号码会清除旧验证状态。管理员在后台修改手机号后，短信已启用时用户须重新验证新号码。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/access` | 返回 `status`、`active`、`canBrowse`、`profileRequired`、`smsRequired`；已完成资料且待审批的扫码用户为 `active=false, canBrowse=true`，资料未完成时附带 `name`、`phone` 供预填 |
| POST | `/api/access/sms` | `{phone}`，发送验证码，返回 `expiresIn`、`resendIn` |
| POST | `/api/access/profile` | 始终提交 `{name, phone}`；`smsRequired=true` 时额外提交 `code`。未验证时不写入号码归属证明，更换号码会清除旧验证状态，返回新的授权状态 |
| POST | `/api/access/join` | `{code, method}` 扫码登记（method 为 scan / code）；需已完成第一步，返回待开通状态和浏览权限 |

浏览权限只开放给资料完整、已扫码并等待审批的用户，覆盖会员开通码、S1 / S2 邀请码、负责人绑定码及推广码。匿名、未登记、被拒绝、停用及资料未完成的账号不会因此获得浏览权限。服务器按路由明确列出允许的本地读取接口；付费上游搜索、发码等具有副作用的 GET 接口仍需开通。只读操作被拒绝时在当前页提示等待开通，不强制退回授权页；生成和付款的事务校验继续要求真正的有效授权。

上线前请在微信公众平台更新《小程序隐私保护指引》，声明收集姓名和手机号的用途。
