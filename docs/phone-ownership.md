# 手机号占用（phone_owners）

每个手机号在 `phone_owners` 中记录归属账号，登录与注册都以它判断“该手机号已被其他账号使用”。删除（归档）账号时会释放其手机号；但历史数据中可能留下未释放的记录，导致号码既登录不上（命中已删除账号）也无法重新注册（提示被占用），后台又搜不到（账号已删除或资料中已没有这个号码）。

现在判断占用时会核对归属账号（`ownerActive`）：只有当该账号存在、未删除，且资料中的手机号或已验证手机号仍是这个号码时，才算占用。否则视为空闲：登录时为该号码新建账号（旧的已删除账号及其数据保持归档不动），注册时可正常使用。停用（未删除）且仍持有该号码的账号继续占用。

后台查找：用户管理默认列表不含已删除账号；按手机号搜索并把状态选为“已删除”才能看到。

## 删除后重新注册（已核对）

超管删除（归档）账号会释放微信关联与手机号。端到端测试 `account_reregister_test.go` 覆盖：同一微信授权该号码、同一微信直接登录、其他微信授权该号码、短信验证码登录，均进入新账号且该号码可重新登记。

易误解的情况：删除账号 A（号码 X）后，同一微信又登录了账号 B（另一个号码）。此时再用该微信授权号码 X，微信已属于 B，不能切换，以前提示“该手机号已被其他账号使用”（号码其实空闲）。现在提示“当前微信已登录其他手机号的账号，请点「使用其他手机号」用短信验证码登录”，按提示用短信登录即可进入 X 的新账号。
