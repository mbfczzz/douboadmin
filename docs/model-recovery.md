# 删除后的模型恢复

模型删除是软删除：模型记录和原定价、提示词等配置保留，默认目录与小程序隐藏该记录。“同步上游”刷新模型能力时仍保留删除状态，不自动恢复主动删除的模型。

同步结果中的“更新”是全部类型的记录更新数，包含仍然隐藏的已删除记录。后台会单独提示其中有多少个已删除模型。

恢复操作：

1. 模型管理中将“模型范围”切换为“已删除模型”，可继续按类型、名称搜索。
2. 点击对应模型的“恢复模型”，确认后服务端重新核验上游目录。
3. 恢复会保留原名称、排序、定价和模型配置；支持创作的模型重新上架。
4. 切回“当前模型”查看。上游已移除的模型不能恢复，版本冲突需刷新后重试。

已有“新增模型 → 输入准确上游模型 ID”的恢复方式继续可用，也会保留原配置。
