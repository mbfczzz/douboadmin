# 登录隐私同意包体积说明

微信审核指出登录前默认同意《用户服务协议》和《隐私政策》。本次增加一个登录与授权页共用的原生勾选组件，默认未选中，协议和隐私政策可分别打开阅读；微信手机号授权、普通微信登录、其他手机号短信获取和短信登录均在用户主动勾选前停止。

没有增加第三方依赖、图片或全局组件。源码依赖估算由 1,127,163 字节增加到 1,130,936 字节，净增 3,773 字节；预算按实测从 1101 KiB 调整为 1105 KiB。该增长用于审核要求的可见状态、复用组件、三条登录路径守卫和回归测试，不以提高上限掩盖其他增长。

该数值是 LF 归一化的引用源码依赖估算，不是 `node_modules` 大小，也不是微信最终上传包；重新上传时继续单独记录开发者工具给出的最终包体积。

后续审核复查发现匿名访问统计会在未同意时生成随机访客标识并发送设备平台，与政策中的“主动开启后统计”不一致。访问和功能点击现默认完全关闭，仅在用户打开“详细使用统计”后发送；设置文案和隐私政策同步说明页面、操作类型、进入场景、设备平台与随机访客标识。合并离线协议后的源码估算为 1,138,864 字节，预算从 1112 KiB 调整为 1113 KiB。

公开分享作品同时增加“AI生成内容”标识和直达客服投诉页的“举报或投诉”入口，源码估算增至 1,139,422 字节，仍在同一 1113 KiB 预算内。
