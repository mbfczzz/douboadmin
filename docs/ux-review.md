# 用户路径复查

此页保留早期演示阶段的历史验证记录；当前真实模型、MySQL 与新增业务的状态以 [报价单验收](quote-implementation.md) 和 [最新细节复查](business-review.md) 为准。

覆盖小程序 12 个页面及其主要状态，以及管理后台登录、概览、模板、任务、用户、模型、反馈、设置。
检查以真实操作顺序为主：进入 → 登录或取消 → 选择内容 → 输入和上传 → 提交 → 查看进度 → 重新编辑或保存 → 退出。

## 已修复的问题

| 用户操作 | 修复结果 |
| --- | --- |
| 点击普通底部 Tab | 直接切换；小豆子过渡保留在去创作、重新编辑、Agent 带入创作等关键入口。 |
| 游客查看任务或收藏、取消登录 | 停留在可返回的页面，提供明确登录按钮；自动刷新不再反复打开登录页。 |
| 重新编辑作品 | 恢复原模型、分辨率、画幅、时长及参考素材。素材恢复失败有重试和清空重选入口，提交时不会悄悄遗漏原素材。 |
| 上传过程中换草稿或离开 | 旧上传、旧素材恢复响应不会改写新草稿；离开照片确认后不会再向原页面添加文件。 |
| 照片上传成功但返回失败 | 重试返回复用已上传的文件，不重复上传或重复添加。 |
| 模型尚未加载或当前类型没有模型 | 显示原因与重试入口，暂停生成，清掉不适用的旧选项。 |
| 生成过程中切换页面 | 完成提交后给出队列提示，不强行拉回任务详情；正在进入详情时的重复点击不会再创建任务。 |
| 发送 Agent 消息、提交反馈后继续输入 | 成功响应只清空已提交的那段内容，保留随后输入的新内容。 |
| 发送消息时恰逢旧轮询返回 | 新消息立即进入对话，旧轮询不会覆盖；回复继续通过任务状态更新。 |
| 网络暂时失败 | 任务、作品、个人资料及收藏保留已有内容，提供可操作的刷新提示。 |
| 参考素材加载失败 | 单独提示素材错误，已完成作品仍可查看与保存。 |
| 重复点击保存作品 | 只启动一次下载；相册权限提示说明授权后如何继续。 |
| 模板被后台下架 | 收藏列表保留“暂不可用”条目并允许取消收藏，避免数量与列表看起来矛盾。 |
| 查看正在生成的“我的作品” | 可见时刷新状态，离开或编辑资料时暂停；资料草稿使用开始编辑时的版本，冲突保留草稿。 |
| 明确退出登录 | 清理本地工作草稿、待提交标记，重新打开首页，避免旧页面留有个人数据。 |
| 输入长昵称、简介、英文提示词、网址或文件名 | 适当截断或换行，避免覆盖其他区域或撑出窄屏；头像占位支持 Unicode 字符。 |
| 后台误关编辑弹窗 | 未保存时确认；键盘焦点保持在弹窗内，关闭后回到入口按钮。 |
| 后台遇到编辑版本冲突 | 保留表单，明确提示再次保存的覆盖含义，错误提示获得焦点。 |
| 后台请求失败或首次加载 | 使用可理解的提示，保留已加载内容；不同时显示“加载中”和空列表结论。 |

## 验证记录

- 小程序构建：TypeScript、WXML/WXSS、组件与事件绑定、文件长度和源码体积检查通过。
- 81 项小程序逻辑与回归测试通过；包含微信工具内置 TypeScript 4.1 的兼容性检查。
- 实际 Go API 联调通过：登录演示账号、模板、收藏、上传、生成、队列、重新编辑、个人数据、反馈、Agent 回复及失败重试。
- 6 项管理后台浏览器流程通过，包括登录失败恢复、模板上下架、任务结果、未保存保护、键盘操作、冲突恢复、网络错误及小程序数据联动。
- 12 个代表页面在 320 px、390 px 两种宽度下，共 24 个静态样式样例通过横向溢出检查。检查包含长文本样例。
- 动效、减少动态效果设置、固定定位与弹层点击层级检查通过。
- Go 单元测试、race 检测与 vet 通过。
- 未新增运行时依赖；手写代码、样式和测试文件仍不超过 300 行。

后台浏览器与小程序 API 联调使用独立测试服务。测试数据未写入当前正在使用的内存服务。

## 运行与验收边界

- 浏览器中的 WXML 样式预览不是微信模拟器。真实微信登录、软键盘、相册权限、隐私指引及原生转场仍需手机验收。
- AI 输出仍为明确标注的演示素材；没有把固定结果当作真实 AI 生成。
- MySQL、Redis、OSS 的真实部署和跨实例环境未在本轮联调；当前本地服务采用内存存储，重启会重置记录。
- 本轮新增的服务端空白反馈校验已在独立服务中验证。当前 8080 API 未因这项小改动重启，以保留已有内存记录；下次启动时构建新代码即可生效。客户端已拦截空白反馈。
- 小程序重新编译后载入这些调整；管理后台刷新后载入。
