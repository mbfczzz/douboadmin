# 火山方舟 Seedance 直连

模型管理里固定有 5 个视频模型（名称带「官方」，如「Seedance 2.0 官方」），直接调用火山方舟官方「视频生成」接口，不经过中转站，也不随「同步上游」变化：

| 模型 | 方舟模型 ID | 清晰度 | 时长 | 参考图 / 视频 / 音频 |
|---|---|---|---|---|
| Seedance 2.5 | doubao-seedance-2-5-260628 | 480p / 720p / 1080p / 4K | 4–30 秒 | 30（本平台单任务最多 20）/ 10 / 10 |
| Seedance 2.5 Flash | doubao-seedance-2-5-flash-261115 | 480p / 720p | 4–30 秒 | 10 / 5 / 5 |
| Seedance 2.0 | doubao-seedance-2-0-260128 | 480p / 720p / 1080p / 4K | 4–15 秒 | 9 / 3 / 3 |
| Seedance 2.0 Fast | doubao-seedance-2-0-fast-260128 | 480p / 720p | 4–15 秒 | 9 / 3 / 3 |
| Seedance 2.0 Mini | doubao-seedance-2-0-mini-260615 | 480p / 720p | 4–15 秒 | 9 / 3 / 3 |

比例：16:9、9:16、4:3、3:4、1:1、21:9；首帧、首尾帧任务按图片比例（方舟 `adaptive`）。生成方式：文生视频、首帧、首尾帧、全能参考。参数、限制和价格取自方舟文档（2026-11）。

- **配置**：后台「服务接入配置 → 火山方舟视频生成」填写独立的 API Key（`ARK_VIDEO_API_KEY`，地址 `ARK_VIDEO_BASE_URL`），保存后重启。未填写时这 5 个模型显示不可用。
- **入口**：只能经由创作的 `/api/jobs/quote` 与 `/api/jobs` 提交（Agent 只能出方案，「确认生成」走同一接口）。
- **服务启动时**：自动登记（`server/internal/arkvideo`）。每次启动恢复官方的清晰度、时长、比例、生成方式和参考上限；名称、排序、上下架和定价等运营设置保留；已删除的不会恢复。
- **计费（后付费）**：方舟成功后返回实际视频 token（`usage.completion_tokens`）。价格为官方元/百万 token × 10（积分/百万 token），按输出清晰度区分「不含 / 含视频输入」，可在「定价」里修改。
  - 提交时按估算 (输入视频秒数 + 输出秒数) × 宽 × 高 × 24 ÷ 1024 × 1.15 预扣。
  - 成功后按实际 token 结算，多余退回，最多扣预扣的部分。
  - 失败、被拒全部退回；提交结果未知时不重复提交，积分待管理员核实。
  - 积分明细写「视频按用量扣除 X 积分（N 视频 token）」。
- **结果**：方舟视频链接 24 小时有效，Worker 生成成功后立即转存到 OSS。
- **时限**：
  - 视频任务 1 小时超时。离超时不足 20 分钟的任务不再提交给方舟，直接超时并退回积分。
  - 提交时带 `execution_expires_after=3600`，方舟一小时内没完成就放弃，不会在本任务超时后再生成、再计费。
  - 提交成功后任务编号立即落库，不受本轮中断影响。
- **提交前检查**（避免扣积分后才被方舟拒绝）：
  - 参考视频总时长：2.0 系列 ≤ 15 秒，2.5 系列 ≤ 30 秒。
  - 2.0 系列只有参考音频、没有图片或视频时不能提交。
- **运营限制**：后台「生成能力」只能在官方的清晰度、比例、时长范围内收窄，不能扩大；每个开放的清晰度都必须填写两项单价。
