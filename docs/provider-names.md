# 服务商同级名称唯一

规则：同一 `parentId`、同一业务层级 `role` 内，未删除、未拒绝的服务商不能重名。名称比较去掉首尾空格，忽略英文大小写；不删除名称内部空格。分公司均位于平台 root 下，因此分公司名称在平台内唯一。不同上级或不同业务层级可以使用相同名称。

后台新增分公司、扫码创建 S1/S2 和超管改名共用服务端校验。待审核、正常、停用记录都占用名称；已拒绝、已删除记录释放名称。重复时返回“同一上级下已存在同级同名服务商，请使用其他名称”，不创建部分账号、不占用手机号、不留下扫码登记。

校验与写入位于现有服务商树事务锁内，共享 MySQL 的多个 API 实例按同一锁串行执行；检查完整记录集，没有 500 条截断。没有新增库或数据库迁移。历史同名记录不自动重命名或删除；不改名的常规状态操作保持兼容，新建和改名必须遵守此规则。

回归覆盖并发新增、去空格及大小写、改名排除自身、不同上级/层级、待审核及停用占名、拒绝/删除后重用、扫码失败回滚、后台手机号及账号创建回滚和超过 500 条的数据。
