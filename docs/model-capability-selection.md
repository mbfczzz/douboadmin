# 画质与清晰度选择

后台「模型管理 → 生成能力」中，取消部分选项会限制小程序的可选档位；取消整组画质或清晰度后，小程序隐藏对应选择项。重新勾选任一选项会恢复显示。

时长、清晰度、画质和比例允许超出上游目录声明的范围，但可选项固定为以下集合；后台不再因上游未声明而置灰。参数按用户实际选择传递，不强制使用最大值。

- 视频时长：1–30 秒的整数，支持全选，无自定义上限。
- 时长和比例一旦选择后至少保留一项，避免全部取消后恢复上游默认值；旧视频配置没有有效时长时，需先选择时长才能保存生成能力。
- 视频清晰度：480P、720P、768P、1080P、2K、4K。
- 比例：1:1、3:2、2:3、16:9、9:16、4:3、3:4、21:9。
- 图片清晰度：1K、2K、4K；画质：低、中、高（接口值 low、medium、high）。

新设置、生成提交和模板保存按固定集合校验；旧配置和上游声明中的额外档位不会出现在可选列表中。既有合法档位保留原大小写，以免改变历史价格键。

图片和视频不再应用上游按生成方式声明的分辨率限制，最终由中转站判断支持情况；未显式配置时使用上游声明与固定集合的交集。账号权限、素材归属、文件大小、积分确认及生成协议检查仍保留。中转站明确拒绝任务后，按既有失败结算逻辑释放预留积分。

参数范围放开需同步部署 API、worker 和管理后台，避免旧 worker 仍按上游范围拒绝任务；现有小程序重新进入创作页即可读取新配置。

整组取消时分别保存 `settings.hideQuality`、`settings.hideResolution`，解决空数组被当作“沿用上游全部选项”、重新打开后恢复全选的问题。历史未配置记录仍沿用上游能力，不会被自动隐藏。

隐藏选择项不代表停止传递必需参数：图片创作默认选择最高可用清晰度（4K → 2K → 1K）和画质（高 → 中 → 低），视频沿用原默认方式。积分预估和生成提交使用相同参数。基础积分及已有价格矩阵保持原样，当前不可选档位的旧价格不会参与计费。

图片首次进入、切换模型或原选项失效时采用最高可用档位；用户手动选择的有效档位在刷新时保留，再编辑旧作品也保留原参数。缓存中的自动默认值会随新配置升级到最新可用最高档，空选项不会被补出不存在的值。

再编辑时先清除旧页面的模型选项，待最新配置到达后恢复明确选择，避免旧缓存先行把低档参数替换成最高档。仅大小写变化的档位按同一档匹配，并使用最新配置中的实际值提交。

同步上游保留隐藏设置。此变更需部署 API、管理后台，并更新小程序；无需数据库迁移。旧版 API 不认识新增字段，旧版小程序不会隐藏选择项。

## 积分优先级

视频按时长计费时，每个清晰度列提供“每秒积分”和“填充本列”。按 `每秒积分 × 秒数` 填充当前已选时长，支持两位小数及 0（免费），可覆盖本列现有值；其他清晰度与未显示时长的价格保留。填充仅修改草稿，仍需保存及二次确认。各格可以继续单独修改；重新打开时，一致的列会显示推算出的每秒积分，混合价格或未填完整的列留空。这是批量录入工具，最终仍保存逐档价格，不改变既有计费接口。

输入了尚未填充的每秒积分时，会提示先填充或清空该输入，避免保存时遗漏。手动改单格或合并并发更新后，该列的每秒积分提示同步重算；其他列尚未填充的输入保留。积分转换已处理大额两位小数的浮点误差，避免多扣 0.01 积分。

- 对应档位有定价时，按该档位的价格扣费；明确填写 0 表示免费。
- 对应档位留空或清空后，按「基础信息 → 消耗积分」计费。回退价格为每次生成的总积分，不再乘以时长。
- 没有可配置的定价档位时，定价页显示基础积分说明，不显示空表格；每次生成使用基础信息的消耗积分。
- 取消全部清晰度选项后，定价页不再显示上游 1K/2K 等列，预估及新任务扣费使用基础消耗积分，不再读取保留的清晰度档位价格。
- 仅取消全部画质选项时，定价页使用“默认（不分画质）”一行；该行未填则按基础积分计费，原有画质行的价格不参与计费。重新启用对应档位后恢复原有价格。
- 固定画质但有清晰度选项的模型，仍可按清晰度定价；历史数字画质不再作为可选项。

预估、提交和最终扣费共用同一计费规则，任务提交后保留已确认价格，后续调价不改变已有任务的扣费。

复核补充：上游已无清晰度档位时，即使旧客户端携带旧参数、配置残留旧价格，也只按基础积分计费。已无画质档位时使用“默认（不分画质）”价格行，不再读取旧画质行。旧数据中的 null 能力列表按空列表展示；并发修改后重试保存定价，仅合并本次变更的价格格子，保留其他管理员的修改。

固定范围复核：时长去重后升序展示，避免旧配置倒序导致滑杆端点与定价行异常。画质显示统一为低/中/高，保留旧大小写值用于传参与价格键匹配，避免标签修正改变实际收费。
