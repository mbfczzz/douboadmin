# Agent 创作项目

Agent 页一次打开一个「创作项目」。每个项目有一个技能、一组素材和自己的对话；对话里的回复会给出可修改的创作方案，确认后直接生成。

## 用户怎么用

1. 选一个技能新建项目（商品带货视频、探店视频、图片创作、自由创作），或直接发消息（自动新建「自由创作」）。顶部项目栏左边「切换 ›」打开项目面板（切换、按技能新建、删除），右边「+ 新建」回到选技能页；回到选技能页后，下次进入仍停在这里，之前的项目留在列表里。
2. 输入框里的「图片」「视频」按钮给**当前这条消息**加附件（图片可一次多选，每条最多 9 个），附件显示在输入框文字上方，点开看大图，× 去掉。附件只随这条消息发送，发完输入框清空；下一次分析要重新上传。只放附件不写字时，按「分析这张图片 / 分析这个视频」发送。
   每个附件同时记进项目素材，按类型编号为 图片1、视频1…（每个项目最多 60 个），方案仍可写 `@图片3` 并用它生成；发出的消息在气泡上方显示它带的附件和编号。
   图片只能发给能识图的模型（选了 DeepSeek Pro 这类模型时提示换模型）；视频任何直连模型都可以，由「视频理解」代看（见 chat-models.md）。
   项目刚建时以技能命名，第一版方案出来后自动改成方案标题。
3. 回复末尾是「创作方案」卡片：标题、时长和比例、按时间的镜头（画面、口播、用到的素材）。
4. 用一句话修改，例如「第二镜换成特写」，模型只改这一处并给出完整新方案；旧方案折叠成一行，点开可以看完整内容并「用这一版生成」。
5. 「确认生成」：自动选第一个（按后台排序）支持所引用素材的模型，时长和比例取最接近的支持值，只带上描述里提到的素材；弹一次积分确认后提交。生成进度以卡片显示在对话里，点开是任务详情。「去编辑页精调」把方案和它提到的素材带到创作页。

## 实现

- 表 `agent_sessions`（标题、技能、素材 ID、删除标记、最近活动时间）；接口 `GET/POST /api/agent/sessions`、`GET/PUT /api/agent/sessions/{id}`、`GET /api/agent/skills`。
- 对话和生成都是普通任务，`input.sessionId` 指向项目；`GET /api/jobs?page=1&session=ID` 取出整个项目对话。项目必须属于本人且未删除，项目内的对话一律按 Agent 对话处理。
- 对话历史只取本项目最近 6 轮（每轮回复保留 4000 字，保证上一版方案完整），系统提示由技能说明、方案格式（`core.agentContract`）和本项目素材清单组成。每轮只发送这条消息的附件；历史轮次不再重发附件，项目素材清单只以名称出现在系统提示里。
- 方案格式：回复最后一个 ```plan 代码块里的 JSON：kind、title、duration、ratio、prompt、shots[time, scene, asset, line]。模型不守格式时的处理（`utils/agent-plan.ts`）：
  - 带 prompt 的 ```json 代码块也算方案；有多个方案块时用最后一个，所有方案块都不显示在文字里。
  - 允许多余逗号；kind 写「视频 / 图片」、比例写「竖屏 / 横屏 / 方形」、时长写「15秒」、素材写「@图片 1」都能识别；时长限制在 1–60 秒。
  - 回复在方案块里被截断、或 JSON 无法解析：不显示代码，提示「方案没有完整输出」并给出「重新整理 ›」。
  - 正文去掉 **加粗**、# 标题，列表改成「·」。
- 生成时只发送方案里提到的素材，并把 @ 引用按实际发送的顺序重新编号（只发项目的图片2 时，提示词里写 @图片1）；项目里没有的素材去掉 @。
- 每个技能带示例说法（空项目里点一下填进输入框）和快捷追问。方案按「第 N 版」编号，旧方案折叠成一行；最新方案的「确认生成」上直接显示这次要扣的积分（用和按钮相同的选模型规则报价，素材变了会重新报价）。
- 技能目前写在 `server/internal/core/agent.go`；之后的「后台技能管理」会让只靠指令的技能可以在后台新增。

## 编辑与复制

- 每条发出的问题下方有「复制」和「编辑」。「编辑」把这一问的文字和附件放回输入框（输入框上方提示，可取消），修改后发送是新的一轮，
  任务带 `input.revises = 原任务 id`；服务端拼对话历史时去掉被修改的那一轮（之后各轮也不再带它），模型按新问题重新回答。
- 回复里值得单独复制的内容显示为「复制」条（最多 6 条，`utils/snippets.ts`）：带标签的行（标题、文案、口播、台词、字幕、提示词、话题等）、
  代码块、两个以上的 #话题，以及 6–200 字的引号内容。点一下复制该条；回复下方的复制按钮仍复制整条回复。
