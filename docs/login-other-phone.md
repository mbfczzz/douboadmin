# 登录：使用其他手机号

一个微信只关联一个豆播账号（`user_identities`）。“手机号授权登录”使用微信绑定的手机号；之前“使用其他手机号”只做微信登录、不带手机号，服务端按微信身份找回已关联的账号，所以退出后点它会直接登回原手机号。

现在点“使用其他手机号”在页面内展开：输入手机号 → 获取验证码（60 秒后可重发）→ 输入 6 位验证码 → 登录。走已有的短信登录接口：

- `POST /api/auth/phone/code` `{phone, source: "miniprogram"}` → `{challenge, resendIn}`
- `POST /api/auth/phone/login` `{phone, code, challenge, source: "miniprogram", wechatCode}`：登录该手机号对应的账号（没有则新建）。`wechatCode` 是本次 `wx.login` 的凭证，服务端换取 OpenID 只写入这次会话（微信支付需要），不改变微信身份与原账号的关联；换取失败时照常登录，只是本次会话不能发起微信支付。

需要在后台配置短信服务；未配置时提示“短信登录服务尚未配置，请联系管理员”。再次点“返回微信登录”收起表单。

授权页（activate）的“使用其他手机号”同样有此问题（只做微信登录），现在跳到 `/pages/login/index?sms=1`：直接显示短信表单；已登录状态下也不会自动返回。登录成功后回到授权页，按新账号刷新开通状态。会话过期一律跳登录页，不会在后台静默用微信身份登回原账号。
