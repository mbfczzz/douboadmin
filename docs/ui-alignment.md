# 小程序与原型对齐

设计来源为用户提供的 `豆播AI.pen`（Pencil 2.21），以可见节点为准。
`enabled: false` 的节点不是当前界面内容。底部导航采用用户随后要求调整的图标方案。

最新视觉覆盖：用户在 2026-11-11 明确要求管理后台与小程序共同参考 `aggc.site` 的深色主题与配色，当前以 [参考主题说明](miniprogram-admin-theme.md) 为准；下方薄荷绿规范保留为前一轮记录，布局与业务结构继续遵循原型及后续要求。

## 新手流程优化

- 模板详情的「生成同款」固定在底部安全区，内容区预留空间；按素材数量明确显示尚缺照片或可生成状态。多张必填照片时持续提供添加入口，零必填时标明选填。
- 登录页精简品牌宣传内容，主按钮在短屏首屏可见；根据生成、上传、收藏、任务、作品等来源说明登录后的下一步，保留返回入口。
- 「我的作品 → 查看全部」和作品数量进入独立作品页，仅展示已完成媒体，支持全部、图片、视频筛选；正在生成的统计与生成记录仍进入任务队列。
- 创作页提供「试试示例」和默认参数提示；示例只填入空输入框，不覆盖已有文字、不自动提交。
- 生成中说明可以离开并到「我的作品」查看，提供继续创作入口。

## 用户明确修改（优先于原型）

- 模板首页采用紧凑间距：分类标签到首行封面 16 px，卡片行距 24 px（原型为约 72 px / 80 px）。
- 授权开通页与登录页统一为居中的品牌头部；直接申请为唯一主按钮，激活码为次要路径。
- 模板详情底部显示本次预计积分，与创作页使用同一估价接口。

## 本次校正

- 创作：移除额外的页首说明和输入区标题；工作台高 300 px，参考素材入口在左上角，展开入口在右上角；底部依次为模型、参数摘要、生成按钮。
- 模型选择：使用工作台下方的就地下拉；只展示服务端配置的可用模型，切换时同步有效的分辨率、比例。
- 素材选择：使用原型中的底部面板，区分图片、视频、音频；图片创作仅提供图片入口。
- 创作参数：分辨率等分一行，时长标题保持单行，画幅每行五项；提示词通过字符串换行，避免显示 HTML 实体。
- 模板：移除额外的卡片操作行和类型切换；还原封面比例、标题字重、留白和「查看更多」入口。
- 我的：对齐头像、统计区、作品卡片和常用功能列表的尺寸，移除额外的页尾品牌文案；展示真实账号数据。
- 模板详情与上传：还原商品照片说明、上传按钮、素材来源面板、补充素材网格和确认照片页。
- 任务：按原型展示进行中/失败列表和最近完成网格；详情采用状态行、结果预览、提示词、参考文件网格和参数摘要，移除额外的大型生成动画卡片。
- 公共标题：为独立标题补充块级布局，保持标题与控件之间的间距。

## 实际运行的适配

- 状态栏、微信胶囊、安全区由微信提供，不照搬画板里的模拟系统界面。
- 用户资料、模板、任务、可选模型来自接口，不把设计示例的账号、数量和未接入模型写死到产品中。
- 演示标识仅在接口明确返回演示状态时显示，不将真实环境标成演示 Provider。
- 原型中的「混剪」和「Agent」正文节点未启用；这些页面保留已实现的业务流程，沿用公共视觉规范。

## 验证方式

`npm run build` 检查 TypeScript、WXML/WXSS、组件与事件绑定、源码体积。
`npm run test:runtime` 覆盖页面注册、模型切换、素材选择与模板分页。
可通过 `DOUBO_TYPESCRIPT_PATH` 指向微信开发者工具内置的 TypeScript，复测兼容性。

浏览器中的 WXML 样式预览用于检查布局和窄屏溢出，不代替微信模拟器和真机验收。

## 页面过渡

底部 Tab 和“去创作”、作品重新编辑、Agent 带入创作等入口直接切换到目标 Tab，保留输入草稿，不再经过 600 ms 中间页。详情进入/返回与登录恢复沿用微信原生路由，不叠加整页透明度动画。缓存页返回时保留已有内容；模板列表保留筛选、加载页和滚动位置，下拉刷新时才重新载入列表。明确退出登录后重新打开模板首页，清除旧页面里的个人数据。

Tab 高亮按当前真实路由同步，不在已离开的页面上修改选中项；快速连点会被拦截，失败可立即重试。只对初次加载内容和局部控件保留轻量动效，减少动态效果设置仍生效。

- 首次载入内容使用 180 ms 局部淡入；模型下拉展开/收起为 160 ms；素材弹层使用 TDesign 的 240 ms 过渡。
- 页面根节点不重播动画；系统开启减少动态效果时关闭自定义过渡。
- 模板列表首次加载展示等高占位；返回列表时保留已有内容及展开页数，下拉刷新重新读取列表。
- 登录完成后等待微信路由动画结束再恢复原操作；旧客户端采用短时兼容等待，避免返回与后续跳转重叠。
- 当前 Tab 的重复点击不再次跳转，切换过程中合并重复操作；接口请求和任务创建不增加动效等待。
- 相册、相机或后台返回同一页面时保持内容可见，弹层与固定按钮不参与父级透明度动画。
- 详情、队列等向前跳转在源页面返回前防止重复压栈；失败立即允许重试，返回箭头也拦截连续点击。
- 登录完成回调绑定当前登录流程；旧页面的回调不影响后来发起的登录。已有会话直接进入登录页时，先完成进入转场再返回。
- 模板的保留内容按分类和搜索条件核对；不将旧分类数据放到新分类下，也不在页面卸载后回写。

## 小程序共同视觉规范（2026-11-11）

- 保留深色底、薄荷绿操作色和用户提供的品牌图片；下拉阴影与编辑器遮罩承担层级作用。原有高亮不做整体删除，不新增渐变或毛玻璃装饰。
- 共享颜色在 `styles/theme.wxss` 的 `--ui-*` 中定义，TDesign 品牌、文字、容器与按钮变量引用同一组值。公共错误提示统一使用危险色、背景和边框；角色色与具体业务状态色保持各自含义。
- 正文 14px、说明 12px、紧凑元信息 11px；预计积分提升到 13px/500 字重，区别于字数计数。模板 27px、创作 19px、其他一级页 23px 的标题按原型保留。
- 输入与常用按钮圆角为 8px，业务卡片为 12px；编辑器等专用容器保留原型尺寸。公共变量用于复用规则，不强行抹平不同层级。
- 关键点击区域至少 44px；创作展开图标视觉中心保持不动，扩大触控框。服务商码切换、复制、积分卡片按钮和窄屏 Tab 提升可点击尺寸。
- 自定义 Tab、创作类型、模型与参数选项补充操作名称及选中提示。原生 switch/slider 的颜色属性仍使用与主题一致的字面色，遵循原生属性类型。
- 混剪未开放时展示接口返回的真实状态和“去创作”出口，隐藏编辑控件并拦截上传；热门视频不可用时也引导至创作。已有混剪草稿数据保留，不启用尚未接入的生成服务。
- 权限、分页与数据接口沿用当前实现；不增加演示业务数据、不修改服务商范围和计费逻辑。
- 主题变量、触控、关闭状态与下列原生布局修复使引用源码估算从 557025 增至 561147 字节（+4122）；第三方引用仍为 200161 字节，既有 548 KiB 预算未提高。源码估算与微信最终上传包分别验收。

### 原生检查补充

- 素材来源面板以显式 `source-copy` 分配正文空间，避免 TDesign 虚拟根节点命中 `> view` 后将图标撑宽；收藏条目使用同样的正文容器约束。
- 模型菜单的可用高度扣除底部 Tab 与手势安全区，空间不足时向上展开；`scroll-view` 采用边框盒，避免声明高度之外再增加内边距和边框。
- 同名模型通过后端公开模型标识作为说明兜底，优先展示运营配置的说明；不重命名模型、不修改实际调用 ID。
- 模型选择框与下拉项共用图标模板及 `availableModels` 数据；切换、重排、签名更新和加载失败均同步到当前选择框。图片采用边框盒保持 22px 尺寸，缺图时沿用通用图标。移除不匹配 TDesign 虚拟根节点的无效标签选择器，不增加运行时依赖。新增 3 项图标同步回归，相关 19 项逻辑测试及 14 项浏览器布局投影通过；23 页构建与原有体积预算通过。按用户要求未操作模拟器，原生效果待复测。
- 原生模拟器已查看授权页、模板空态、创作页、视频和图片模型菜单、素材面板、展开编辑器、混剪关闭状态、Agent 空态及“我的”真实作品列表。上述布局缺陷的修复后原生复测尚未完成：用户继续使用模拟器，按要求暂停操作。资料、充值、服务商等子页的浏览器样式测试与代码检查不等同于原生逐页验收。

### 本轮验证

23 页构建和结构检查通过。小程序全量 324 项回归通过；随后新增同名模型区分用例，所在文件 6 项定向测试通过。浏览器样式投影 23 项通过，包含 320、375、430px 下的正文容器、资料表单及菜单边框盒约束。后端 8 项定向测试覆盖分页边界、用户数据隔离、通知与收藏超过旧上限的场景。日志为 `.runtime/mini-ui-final-build.log`、`mini-ui-final-tests.log`、`mini-ui-final-layout.json`。未提高体积上限，未改变业务库结构。
