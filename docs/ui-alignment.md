# 小程序与原型对齐

设计来源为用户提供的 `豆播AI.pen`（Pencil 2.21），以可见节点为准。
`enabled: false` 的节点不是当前界面内容。底部导航采用用户随后要求调整的图标方案。

## 当前视觉基准：即梦 App 深色方向（2026-11-12 收尾）

以下为当前实现，覆盖本文后面的历史方案。参考既有即梦手机端截图的深色、浅色主按钮和内容优先布局，并保留豆播的业务流程；不是对即梦每个页面的逐像素复刻。管理后台不改主题。

- 页面 `#0f0f11`、卡片 `#24252b`、输入框 `#2f3238`、选中底 `#474b54`、弹层 `#27292f`。卡片靠底色分组，无装饰投影或渐变；浮层、错误、聚焦与底栏保留必要边界。底栏 `#191a1f`，只有当前页面标签高亮，中间创作按钮仍保留可见文字。
- 主文字 `#ffffff`、说明 `#a6a8ad`、占位 `#868a93`、链接 `#dbe3e9`。主按钮 `#ebf8ff` 配 `#15161a`；禁用底 `#34373e`，能与卡片区分。青色用于开关、滑块等小面积控件；成功、等待、生成中、失败保留各自的状态色和文字，不为统一装饰色牺牲状态识别。
- 页面边距 20px；普通卡片圆角 20px，小控件约 10px，整行主按钮和搜索框为胶囊。分段选中态用亮灰底与浅色细框，文字标签用下划线。
- 字号用 px：页面及导航标题 20、区块标题 16、正文和输入框 15、说明 13、时间/计数/角标 12。余额、积分与金额按主次保留 18–34px；不把数字展示强制降为正文大小。区块与选中项用 500，主要数字及按钮用 600。
- TDesign 图标为主：文字旁 16、列表和操作 20、导航和功能入口 24、头像/媒体占位 32、空状态 40。模型品牌图片仍是 22px；图标的视觉尺寸与按钮触控范围分别处理。积分四角星 ✦ 暂用文字字符，实际字形需真机确认。

### 页面与交互

- 创作页保持模式切换、输入卡片、参数区的顺序，生成按钮位于输入卡片右下角，参数摘要在模型名下。此前把整个参数区移到输入卡片上方的尝试已撤回，以免生成按钮被挤出短屏。输入区四行、字数与积分信息分开；模型错误优先显示，避免重复红色提示。
- 模板首页为两列竖图流；空列表提供可用的“去创作”，搜索支持一键清空并重新请求第一页，旧搜索响应不会覆盖新结果。
- 模板详情只在底部显示素材准备状态，上传行保留文件名和删除操作。移除上传流程中间的任务队列卡片；提交成功仍进入任务详情。确认照片页上传成功但尚未返回时显示“已上传”，底部按钮栏有背景和内容避让。
- “我的”居中头部、真实统计与近期作品保留；任务详情使用紧凑余额、独立分享按钮和底部删除入口。普通卡片没有装饰描边，选中与危险操作仍清楚可辨。
- 钱包 4 个套餐排成 2×2，积分单位单独一行，避免 320px 下拆字。“充值订单”和“积分说明”位于同一卡片的两行。支付确认时隐藏新购表单、突出“查看订单”；查单超时才提供次要的“另购积分”，仍须确认原单可能到账，不清除原订单。
- 空状态文字与按钮上下排列；重试、去创作等出口使用浅色主按钮。服务商码标签使用简称，二维码下保留全称和说明。品牌图片保持原样，未重新设计品牌资产。

## 历史视觉基准：创作工作台浅色主题（已被上述深色方案覆盖）

用户最新要求不必沿用会员中心参考图，改为适合 AI 图片/视频创作业务的整体配色。保留浅色背景 `#f4f6f8` 与白色普通卡片；靛蓝主操作 `#4255c7`，链接/选中正文 `#3445aa`，选中底 `#eef0ff`；青绿信息/进行中 `#0b7269` / `#e9f6f3`；琥珀积分 `#825718`、浅琥珀底 `#fff8e8`、边界 `#e7d1a4`。成功、警告、失败使用独立语义色；红色集中用于异常及危险操作。此规则覆盖此前的红金及历史蓝色取值，管理后台未改主题。

全局控件、弹窗、原生开关和滑块同步操作色；积分卡/套餐积分/订单积分使用琥珀色。模型推荐标签不使用错误色，Agent 用户与助手对话使用不同浅色层次。自定义底栏保留独立颜色兜底，避免没有继承页面 CSS 变量时退回黑色。主按钮白字对比度约 6.26:1，选中文字约 7.19:1，琥珀正文约 5.97:1、辅助文字约 4.86:1，青绿信息文字约 5.22:1。未引入渐变资产、额外图片或组件库。

### 业务场景复查

- 订单颜色依照实际显示状态：待支付/需核对为琥珀，确认到账/退款处理中为青绿，已支付为绿色，过期/关闭/已退款为中性色。已过期但仍在查单的订单继续显示进行中，付款判断不变。
- 排队为琥珀、生成中为青绿、完成为绿色、失败为危险红；任务详情的图标与文字共同继承状态色。失败数量为 0 时保持中性。
- 服务商待开通与已停用区分为琥珀和中性色，二维码类别选中沿用靛蓝。暂未开放的热门灵感不再作为红色系统错误展示。
- 估价失败用警告色并保留重试；资料表单错误边界使用危险色。套餐、切换选项和分页的禁用态区别于可操作态。
- 删除作品、重置后台密码、放弃未保存资料的原生确认按钮使用危险色。普通支出不使用错误红；积分增加继续显示绿色并保留正负号及业务说明。
- 复用公共状态标签，校验色、背景色和语义文字保持一致；相关订单状态回归、原生确认流程回归、组件颜色检查和 23 页编译通过。未进行真实支付/重置/删除或真机操作。

创作页最新补充：可用积分与本次预计消耗同排，字数统计单独位于其上方；下方只保留模型选择与生成按钮，参数摘要显示在模型名称下。余额直接读取钱包接口，独立于本次预计消耗。点击余额进入积分页，余额或估价失败时分别原位重试，参数区不再重复放置余额组件。

后续 v4 覆盖：生成按钮移回输入卡片右下角；按用户真机反馈，模型、积分/参数摘要、生成按钮在卡片底部同一行排列，按钮简写“生成”，长模型名省略，完整名称可在下拉选择时查看。删除“试试示例”及推荐词入口。“我的”恢复真实创作统计与两件最近作品，常用功能采用图标宫格；积分卡金额独占一行。积分页增加预留说明与套餐选中摘要，单套餐占满一行；订单页显示商品名、金额、积分、状态、时间和可复制订单号，保留原支付限制。设计例图、示例套餐及金额不写入客户端。对应有意源码增量见 [v4 预算说明](miniprogram-ui-v4-budget.md)。

## 新手流程优化

- 模板详情的「生成同款」固定在底部安全区，内容区预留空间；按素材数量明确显示尚缺照片或可生成状态。多张必填照片时持续提供添加入口，零必填时标明选填。
- 登录页精简品牌宣传内容，主按钮在短屏首屏可见；根据生成、上传、收藏、任务、作品等来源说明登录后的下一步，保留返回入口。
- 「我的作品 → 查看全部」和作品数量进入独立作品页，仅展示已完成媒体，支持全部、图片、视频筛选；正在生成的统计与生成记录仍进入任务队列。
- 创作页提供「试试示例」和默认参数提示；示例只填入空输入框，不覆盖已有文字、不自动提交。
- 生成中说明可以离开并到「我的作品」查看，提供继续创作入口。

- 授权开通页与登录页统一为居中的品牌头部；直接申请为唯一主按钮，激活码为次要路径。

## 本次校正

- 创作：移除额外的页首说明和输入区标题；工作台高 300 px，参考素材入口在左上角，展开入口在右上角；底部依次为模型、参数摘要、生成按钮。
- 模型选择：使用工作台下方的就地下拉；只展示服务端配置的可用模型，切换时同步有效的分辨率、比例。
- 素材选择：使用原型中的底部面板，区分图片、视频、音频；图片创作仅提供图片入口。
- 创作参数：分辨率等分一行，时长标题保持单行，画幅每行五项；提示词通过字符串换行，避免显示 HTML 实体。
- 模板：移除额外的卡片操作行和类型切换；还原封面比例、标题字重、留白和「查看更多」入口。
- 我的：对齐头像、统计区、作品卡片和常用功能列表的尺寸，移除额外的页尾品牌文案；展示真实账号数据。
- 模板详情与上传：还原商品照片说明、上传按钮、素材来源面板、补充素材网格和确认照片页。
- 任务：按原型展示进行中/失败列表和最近完成网格；详情采用状态行、结果预览、提示词、参考文件网格和参数摘要，移除额外的大型生成动画卡片。
- 公共标题：为独立标题补充块级布局，保持标题与控件之间的间距。

## 实际运行的适配

- 状态栏、微信胶囊、安全区由微信提供，不照搬画板里的模拟系统界面。

## 页面过渡

底部 Tab 和“去创作”、作品重新编辑、Agent 带入创作等入口直接切换到目标 Tab，保留输入草稿，不再经过 600 ms 中间页。详情进入/返回与登录恢复沿用微信原生路由，不叠加整页透明度动画。缓存页返回时保留已有内容；模板列表保留筛选、加载页和滚动位置，下拉刷新时才重新载入列表。明确退出登录后重新打开模板首页，清除旧页面里的个人数据。

Tab 高亮按当前真实路由同步，不在已离开的页面上修改选中项；快速连点会被拦截，失败可立即重试。只对初次加载内容和局部控件保留轻量动效，减少动态效果设置仍生效。

- 首次载入内容使用 180 ms 局部淡入；模型下拉展开/收起为 160 ms；素材弹层使用 TDesign 的 240 ms 过渡。
- 页面根节点不重播动画；系统开启减少动态效果时关闭自定义过渡。
- 模板列表首次加载展示等高占位；返回列表时保留已有内容及展开页数，下拉刷新重新读取列表。
- 登录完成后等待微信路由动画结束再恢复原操作；旧客户端采用短时兼容等待，避免返回与后续跳转重叠。
- 当前 Tab 的重复点击不再次跳转，切换过程中合并重复操作；接口请求和任务创建不增加动效等待。
- 相册、相机或后台返回同一页面时保持内容可见，弹层与固定按钮不参与父级透明度动画。
- 详情、队列等向前跳转在源页面返回前防止重复压栈；失败立即允许重试，返回箭头也拦截连续点击。
- 登录完成回调绑定当前登录流程；旧页面的回调不影响后来发起的登录。已有会话直接进入登录页时，先完成进入转场再返回。
- 模板的保留内容按分类和搜索条件核对；不将旧分类数据放到新分类下，也不在页面卸载后回写。

## 小程序共同视觉规范（2026-11-11）

- 保留深色底、薄荷绿操作色和用户提供的品牌图片；下拉阴影与编辑器遮罩承担层级作用。原有高亮不做整体删除，不新增渐变或毛玻璃装饰。
