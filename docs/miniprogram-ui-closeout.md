# 小程序 UI 收尾记录（2026-11-12）

本轮在已有未提交的即梦深色方向改版上收尾。当前规则见
[UI 对齐说明](ui-alignment.md)，管理后台界面和业务接口未修改。

## 已完成

- 模板空状态的“去创作”补齐事件处理，使用现有 Tab 跳转保护；没有触发生成或计费请求。
- 模板搜索新增清空入口，清空后加载第一页，之前的搜索响应不能覆盖新结果。
- 模板详情删除上传流程中间的任务队列卡片及其无用代码；“照片已就绪”只留在底部。
- 确认照片页在上传成功而返回尚未完成时明确显示“已上传”；固定按钮栏有底色，正文预留底部空间。
- 支付等待突出“查看订单”，隐藏新购表单。只有查单超时后才提供次要的另购入口，保留原有风险确认、原订单和重复支付保护。
- 钱包的充值订单和积分说明改为同一卡片内的两行；套餐的数字与单位分行，单位不拆字。
- 清理残留的 14px 正文、19px 默认导航标题、14/28px 图标和 rpx 加载图标。模型品牌图与大额数字保留用途对应的尺寸。
- 创作提示词区按四行、22px 行高布局，末行不与字数统计重叠。
- 积分和设置页未登录提示与按钮上下分开；模板和任务等空状态保留明确的下一步。
- 删除已移除入口的代码、未使用字段和重复样式，使构建重新满足既有 566 KiB 限额；本次收尾没有继续提高预算。

## 截图范围和限制

临时工具读取实际 WXML/WXSS 并使用示例数据，覆盖 23 页、67 种状态。
分别使用 320×568 和 375×812 视口；每种状态保存首屏和长图。
截图与测量输出在 `.runtime/miniprogram-closeout/`，不纳入发布包。

修正了此前把 375px 页面截成 320px 的投影错误。长图不再通过增高浏览器视口生成，避免把底部固定操作挪到长页面末尾；纵向 scroll-view 在投影中也保留独立滚动。

这些是浏览器投影，不是微信开发者工具或真机截图。微信原生键盘、权限/支付弹窗、实际字体及 ✦ 字形、最终上传包大小尚须在微信环境核验。示例封面和二维码仅供布局检查，不进入产品代码。

品牌图片保持用户提供的原图。成功/失败等状态色、支付超时后的恢复入口属于业务反馈，未按纯装饰性的简化建议删除。
