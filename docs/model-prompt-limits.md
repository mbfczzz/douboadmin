# 创作提示词字数

在管理后台「模型管理 → 对应模型 → 提示词 → 最大提示词字数」设置每个模型的上限。保存并确认后，小程序重新进入创作页会刷新模型配置，计数器、输入上限和生成校验随所选模型更新。

- 图片模型未配置或配置为 `0` 时默认 **2000** 字。
- 视频模型未配置或配置为 `0` 时默认 **20000** 字。
- 已保存的非零限制继续生效，例如原先明确设置的 `500` 不会被自动覆盖；填 `0` 恢复类型默认值。
- 图片、视频支持配置 `1–100000` 的整数；其他类型保持原有 500 字范围。
- 默认提示词和每条灵感提示词不得超过该模型的有效限制。

`/api/config` 返回有效的 `settings.maxPromptChars`；未设置的模型无需数据迁移。上游模型同步保留运营配置。生成接口根据实际模型类型和已保存配置校验，不再用统一的 500 字限制拦截图片、视频任务，也不信任客户端传入的限制。

切换模型、刷新配置和恢复草稿都保留已有描述。如果新模型的上限更小，用户需要缩短描述后提交，不会静默截断。这里控制的是本系统允许提交的长度，上游服务仍可能有自己的限制。
