# 账号操作统一由超级管理员管理

当前规则：只有真实 `super_admin` 角色可新建后台登录账号、开通服务商登录、重置他人密码、修改账号资料/角色、启用、停用、删除、管理会员授权、处理登记、重置邀请码及解除绑定。菜单权限或角色显示名称为“超级管理员”不等于具备该权限；无角色的旧会话也不能执行这些写操作。

最新规则：所有非超管后台账号仅有三类业务权限：给下级设置算力分佣比例、查看下级活动轨迹、查看分佣。本人修改登录密码及退出登录按用户此前确认保留。即使旧角色勾选了其他菜单，服务端固定白名单和前端菜单也不会开放额外功能；角色编辑只显示固定权限。分享码、会员登记管理、模板、用户管理、账号管理、平台设置、全局日志、提现申请与打款操作均不向非超管开放。

算力分佣比例仍执行原来的下级范围及比例上限校验；同一个接口携带名称、状态、层级、归属或售价变化时，非超管返回403。未关联服务商的非超管账号没有全平台数据范围，其下级列表与分佣列表为空。

下级活动通过 `/admin/partners/{id}/activity` 分页读取：对具体下级可查看其后台账号、负责人及当前关联会员的操作摘要；查看自身服务商节点时只含下级会员轨迹，不含自身后台操作。上级、同级及其他分支均不可查看。解绑/拒绝的会员不再进入该范围；响应不含原始请求、响应、IP、设备信息或错误原文。查询在数据库中限定归属并使用游标分页，不是先查全平台再在页面过滤。

小程序服务商中心不再提供后台账号开通/重置或展示密码；旧版客户端调用 `/provider/password` 同样返回403。登录账号由超管分配，不影响用户自行填写资料、登录、扫码登记和等待开通的流程。

## 删除语义

- 后台账号的删除将 `disabled`、`archived` 设为 true，使旧登录会话失效，并从账号列表移除。服务商登录账号同样支持删除，不删除其服务商业务节点、订单、分佣或审计数据。
- 小程序用户删除使用既有账号注销逻辑，保留历史业务记录；默认用户列表隐藏已删除项，可用“已删除”筛选查看。
- 当前登录的超管不能删除或停用自己；既有最后一个有效超管保护及版本冲突校验保留。

本轮不执行任何真实账号删除、停用或密码重置。代码部署后生效；非超管已打开的旧页面也会被新服务端拒绝写入。

## 二次复查补充

- 页面及弹窗缓存随账号、角色、服务商归属或权限范围变更而重建；身份请求使用取消和版本保护，迟到响应不能恢复旧菜单。确认账号不可用后退出工作台。
- 查询收到401、403或404时清除该查询的旧数据；普通网络/服务故障继续保留可读缓存。筛选条件按账号、角色、归属分开保存。
- 非超管的分佣比例写入在服务商树事务锁内重新检查当前账号、服务商状态、下级关系、上限和版本；方法只接收比例，不写账号资料。新增回归模拟上限降低及账号停用发生在预检查与提交之间，确认拒绝后下级数据未变。
