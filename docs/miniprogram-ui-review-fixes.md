# 小程序界面复查修复（2026-11-12）

在最新代码上按页面和状态投影复查后的 14 项修复，均为样式、文案和既有数据的展示调整，没有新增依赖或接口。

- 积分页"刷新"按钮补 `width: auto`。微信 v2 按钮默认宽 184px，原来会把余额挤成两行。
- 分享页预览固定 240px 高，竖版作品不再把标题和分享按钮挤出首屏。
- "生成中"改用蓝色 `--ui-info`，与成功绿明显区分；金色积分变量改名为 `--ui-points-*` 并收敛到主色系浅靛蓝。
- 充值订单、消息、热门视频的空状态统一为图标在上、文字在下；没有未读消息时隐藏"全部已读"。
- 热门视频在读到服务状态前不提示"不可用"；确认不可用时只显示说明和"去创作"。
- "我的"未登录说明与登录页的手机号授权一致；设置并入常用功能（3×2），服务商中心/推广码单独一行。
- 模型菜单的积分价格移到说明行，模型名独占首行。
- 资料页按是否已验证手机号显示"姓名必填/选填"；模板全库为空时不再建议"换个分类"。
- 任务队列、我的作品复用后端已有的 `thumbnailUrl` 显示视频封面，加载失败回退播放图标（`services/cover.ts`，与"我的"共用）。
- 品牌图保持用户原图，仅以圆角加阴影展示；浅色版需另行提供。
