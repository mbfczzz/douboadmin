# 普通用户注册包体积说明

管理后台恢复“开放普通用户注册”开关。关闭时继续要求邀请码登记和审核；开启后，已完成手机号注册的用户可选择直接使用，邀请码入口保持不变。

小程序只新增授权页上的条件按钮、服务端返回的 `openSignup` 状态和会话隔离的直开请求，没有引入组件、图片或第三方依赖。从服务商小程序码进入时隐藏直开按钮，保证邀请码优先，不改变服务商归属与分佣。

普通注册单项曾使源码依赖估算从 1,127,249 字节增加到 1,128,318 字节。正式提审随后移除体验版自动调试并改用生产 HTTPS，合并后的估算降为 1,127,163 字节，预算恢复为 1101 KiB。微信最终上传包仍须在上传阶段单独核验，不能用该源码估算代替。
