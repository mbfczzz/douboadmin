# 协议离线兜底包体积说明

微信审核截图显示协议页面因临时网络失败而为空白。生产接口恢复后返回内容完整，但审核入口不能依赖单次网络请求或后端部署版本，因此小程序内置《用户服务协议》《隐私政策》和客服联系方式，并始终直接展示安装包内已审核的完整文本，不再由网络响应覆盖。

隐私政策明确列出手机号和姓名的收集方式、信息范围、使用目的，用户主动选择的提示词与图片视频处理方式，订单支付用途、境内存储期限、安全措施，以及查询、更正、删除、撤回同意和注销账号渠道。

源码依赖估算由 1,130,936 字节增加到 1,138,567 字节，净增 7,631 字节；预算按实测从 1105 KiB 调整为 1112 KiB。没有新增第三方依赖或图片。该值不是微信最终上传包，上传时仍单独记录开发者工具报告的包体积。
